A high-performance microservice protected by **WheelGate X: The AI-Independent Python Wheel Trust Gate**.

## Supply Chain Security Invariant
Every pull request modifying `requirements.txt` is intercepted by WheelGate X:
- **Baseline Allowlist:** Only approved startup hooks can execute.
- **Differential Hook Inspection:** `.pth` startup scripts are diffed against the approved baseline.
- **AI-Decoupled Merge Authorization:** Amazon Bedrock Agent explains findings, but cannot authorize merges.
